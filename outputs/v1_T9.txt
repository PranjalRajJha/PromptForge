## 1. Summary
This lecture covers the fundamental role of an Operating System (OS) as an interface between hardware and the user. It explains how the OS manages system resources like CPU, memory, and I/O devices to ensure efficient execution. Key topics include process states, scheduling, and the distinction between kernel and user modes.

## 2. Key Concepts
*   **OS Role:** Acts as an intermediary between computer hardware and the user.
*   **Kernel:** The core component of the OS that manages system resources.
*   **Process States:** The lifecycle of a process (New, Ready, Running, Waiting, Terminated).
*   **Scheduling:** Algorithms used to allocate CPU time to processes.
*   **System Calls:** The interface between a process and the OS.

## 3. Key Definitions
| Term | Definition |
| :--- | :--- |
| **Process** | A program in execution. |
| **Kernel** | The central part of the OS that controls everything. |
| **Throughput** | The number of processes completed per unit time. |

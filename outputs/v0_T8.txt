# Study Pack: Database Normalization

This study pack covers the basics of database normalization as outlined in your lecture notes. Normalization is the process of organizing data in a database to reduce redundancy and improve data integrity.

---

### 1. Short Summary
Normalization is a technique used to structure tables in a relational database. By following specific rules (Normal Forms), we ensure that each table contains logical, non-redundant data. This prevents issues like data duplication and update anomalies. For this course, you are expected to master 1NF, 2NF, and 3NF.

---

### 2. Key Concepts
*   **1NF (First Normal Form):** Focuses on the "shape" of the data. Every cell must contain a single, atomic value (no lists or sets in one cell).
*   **2NF (Second Normal Form):** Focuses on the relationship between non-key attributes and the primary key. It requires that all non-key attributes depend on the *entire* primary key, not just a part of it.
*   **3NF (Third Normal Form):** Focuses on removing "indirect" relationships. It requires that non-key attributes do not depend on other non-key attributes (no transitive dependencies).

---

### 3. Important Definitions
*   **Atomic Value:** A value that cannot be broken down further (e.g., a single phone number rather than a list of three).
*   **Primary Key:** A unique identifier for a record in a table.
*   **Partial Dependency:** When an attribute depends on only *part* of a composite primary key.
*   **Transitive Dependency:** When an attribute depends on another attribute, which in turn depends on the primary key (A → B → C).

---

### 4. Practice Questions

**Q1: If a table has a column containing multiple values separated by commas (e.g., "Red, Blue, Green"), which Normal Form is it violating?**
*   **Answer:** 1NF. 1NF requires all values to be atomic (single values).

**Q2: You have a table with a composite primary key (Student_ID, Course_ID). You notice that the "Instructor_Name" depends only on "Course_ID." Is this table in 2NF?**
*   **Answer:** No. This is a partial dependency because "Instructor_Name" depends on only part of the primary key.

**Q3: True or False: If a table is in 3NF, it is automatically in 1NF and 2NF.**
*   **Answer:** True. Each normal form builds upon the previous one. To reach 3NF, you must have already satisfied the requirements for 1NF and 2NF.

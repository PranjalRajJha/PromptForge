## 1. Summary
A stack is a fundamental linear data structure that follows the Last-In, First-Out (LIFO) principle. This means the last element added to the stack is the first one to be removed. It primarily supports two core operations, push and pop, to manage data insertion and deletion.

## 2. Key Concepts
*   Stacks operate on the LIFO (Last-In, First-Out) principle.
*   Data is added and removed from only one end of the structure.
*   The push operation is used to insert an element.
*   The pop operation is used to remove an element.

## 3. Key Definitions
| Term | Definition |
| :--- | :--- |
| Stack | A linear data structure following the LIFO principle. |
| Push | The operation of adding an element to the stack. |
| Pop | The operation of removing an element from the stack. |
| LIFO | Last-In, First-Out; the order of processing elements. |

## 5. Practice Questions
**MCQs:**
1. Which principle does a stack follow?
   a) FIFO b) LIFO c) LILO d) FILO (Correct: b)
2. Which operation adds an element to a stack?
   a) Pop b) Push c) Insert d) Add (Correct: b)
3. Which operation removes an element from a stack?
   a) Pop b) Push c) Delete d) Remove (Correct: a)
4. In a stack, where does insertion occur?
   a) Both ends b) Middle c) One end d) Anywhere (Correct: c)
5. If you push 1, 2, 3, what comes out first on pop?
   a) 1 b) 2 c) 3 d) None (Correct: c)

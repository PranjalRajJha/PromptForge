## 1. Summary
CPU scheduling is the process of determining which task in the ready queue gets access to the CPU next. Common algorithms include FCFS, which processes tasks in arrival order, SJF, which prioritizes the shortest tasks to reduce waiting time, and Round Robin, which uses time-slicing. Each method involves trade-offs between simplicity, efficiency, and the risk of process starvation or overhead.

## 2. Key Concepts
*   **FCFS:** Executes processes based on their arrival sequence.
*   **Convoy Effect:** Short processes delayed by a single long process.
*   **SJF:** Prioritizes processes with the smallest CPU burst time.
*   **Starvation:** Long processes never getting CPU time due to shorter tasks.
*   **Round Robin:** Assigns a fixed time quantum to each process.
*   **Context-Switch Overhead:** Performance cost of switching between processes.

## 3. Key Definitions
| Term | Definition |
| :--- | :--- |
| CPU Scheduling | Deciding which ready process runs on the CPU next. |
| Time Quantum | A fixed time limit assigned to a process in Round Robin. |
| CPU Burst | The duration a process requires the CPU to execute. |

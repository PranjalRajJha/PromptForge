## 1. Summary
A Deterministic Finite Automaton (DFA) is a machine where each state has exactly one transition per input symbol. In contrast, a Nondeterministic Finite Automaton (NFA) allows multiple transitions, no transitions, or epsilon transitions for a single input. Despite these structural differences, both models recognize the same class of regular languages. Any NFA can be converted into an equivalent DFA using the subset construction method.

## 2. Key Concepts
*   DFAs require exactly one transition per input symbol for every state.
*   NFAs allow flexibility with multiple, zero, or epsilon transitions.
*   Epsilon transitions allow state changes without reading any input.
*   DFAs and NFAs are computationally equivalent in terms of language recognition.
*   Subset construction is the standard algorithm to convert an NFA to a DFA.

## 3. Key Definitions
| Term | Definition |
| :--- | :--- |
| DFA | A machine with exactly one transition per input symbol. |
| NFA | A machine allowing multiple, zero, or epsilon transitions. |
| Epsilon Transition | A move between states without consuming input symbols. |
| Subset Construction | The process of converting an NFA into an equivalent DFA. |

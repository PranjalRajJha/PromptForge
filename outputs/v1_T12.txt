## 1. Summary
A stack is a fundamental linear data structure that follows the Last-In-First-Out (LIFO) principle. It operates primarily through two operations: 'push' to add elements to the top and 'pop' to remove them from the top. Stacks are essential in computing for managing function calls and implementing undo operations in software.

## 2. Key Concepts
*   Stack is a linear data structure.
*   It follows the LIFO (Last-In-First-Out) principle.
*   Push operation adds an element to the top.
*   Pop operation removes an element from the top.
*   Common applications include function call management and undo features.

## 3. Key Definitions
| Term | Definition |
| :--- | :--- |
| Stack | A data structure where the last element added is the first one removed. |
| Push | The operation of inserting a new element onto the top of the stack. |
| Pop | The operation of deleting the top element from the stack. |
| LIFO | A principle where the most recently added item is processed first. |

## 1. Summary
Normalization is a database design process used to minimize data redundancy and prevent update anomalies. It organizes data into specific forms (1NF, 2NF, and 3NF) by enforcing rules on attribute dependencies. The process ensures that database decomposition remains lossless, allowing the original table to be reconstructed accurately.

## 2. Key Concepts
*   Normalization reduces redundancy and update anomalies.
*   1NF requires atomic values and no repeating groups.
*   2NF eliminates partial functional dependencies.
*   3NF eliminates transitive dependencies.
*   Lossless decomposition ensures data integrity during table splitting.

## 3. Key Definitions
| Term | Definition |
| :--- | :--- |
| 1NF | A state where all attributes hold atomic values. |
| 2NF | 1NF plus no non-key attribute depends on part of a composite key. |
| 3NF | 2NF plus no non-key attribute depends transitively on the primary key. |
| Lossless Decomposition | Splitting a table such that the original can be recovered via joins. |
